# Vendor-Performace-analysis
Vendor performance analysis using SQL, Python, and Power BI to uncover business insights and optimization opportunities.

## 📌 Overview

An end-to-end data analytics project focused on analyzing **vendor sales, purchases, profitability, inventory, and cost performance** to identify key business insights and optimization opportunities.

## 🛠️ Tools Used

**SQL | Python | Pandas | SQLite | Power BI**

## 📊 Dataset

The project used 4 raw CSV files containing approximately **31.6 million records**:

* Purchase Price — 110,355 records
* Purchases — 16.77M records
* Vendor Invoice — 50,271 records
* Sales — 14.68M records

## 🔄 Workflow

**Raw CSV → Database → Data Ingestion → Vendor Summary → SQL/Python Analysis → EDA → Power BI Dashboard → Business Insights**

## 🔍 Key Insights

* Top 10 vendors contributed approximately **65.69% of total purchases**.
* Approximately **$2.71M** worth of unsold inventory was identified.
* Larger purchase quantities showed significantly lower unit costs.
* Profit margin alone was not sufficient to evaluate overall vendor performance.

## 💡 Business Focus

The analysis provided insights into:

* Vendor concentration
* Purchasing and cost optimization
* Inventory management
* Profitability
* Vendor performance
